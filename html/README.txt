RAÍZES DO NORDESTE - VERSÃO ORGANIZADA

1. Copie a pasta "imagens" do seu projeto original para dentro desta pasta.
2. Mantenha os nomes das imagens usados no index:
   cuscuz.png
   cuscuzr.png
   tapioca.png
   bolo.png
   sucos.png
   cafe.png
   cliente1.jpg
   cliente2.jpg
   cliente3.jpg

3. Abra o index.html no navegador.

FUNCIONALIDADES:
- Cadastro com validação e armazenamento local.
- Login.
- Identificação do usuário logado no menu.
- Carrinho com quantidade, remoção, limpeza e total.
- Checkout.
- Endereço de entrega.
- Forma de pagamento.
- Registro do pedido no localStorage.
- Página de confirmação.
- Páginas separadas de entrega e pagamento.
- Rodapé reorganizado para não repetir o menu superior.

OBSERVAÇÃO:
Este projeto usa localStorage para fins acadêmicos/demonstração. Não é adequado para armazenar senhas ou processar pagamentos reais em produção.
